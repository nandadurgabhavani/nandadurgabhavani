## 🚀 Featured Projects

### 1. Refund Likelihood Prediction & Customer Retention

**Goal:** Estimate the likelihood of an e-commerce order being returned and classify it as a higher- or lower-risk case.

- Uses customer and order details such as product category, price, quantity, payment method, shipping method, and return timing.
- Presents a prediction through a dashboard to help explore return-risk patterns.
- Built using Python, Pandas, NumPy, Scikit-learn, and Streamlit.

**Repository:** [refund_retention-app](https://github.com/nandadurgab-cmyk/refund_retention-app)

### 2. Chat Guardian — Flask Chat Safety Demo

**Goal:** Explore how a chat application can flag messages containing offensive language.

- Uses a Flask web application for the chat interface.
- Explores message filtering with a profanity-detection library.
- Uses MySQL for database practice.

_This is a learning/demo project, not a complete production-grade content moderation system._

### 3. Maps, Flood Awareness & Robotics — Exploring Ideas

I'm exploring how map-based applications could highlight possible flood-affected areas using weather data, and how robots can receive movement commands through Wi-Fi or Bluetooth. These are learning and research interests, not completed projects.
